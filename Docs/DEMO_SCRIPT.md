# 시연 영상 촬영 대본 (약 60초, 1920×1080 MP4)

> **상태: 아직 촬영하지 않았습니다.** 아래는 촬영용 타임라인이며, 영상 파일은 만들어지지 않았습니다.
> 영상 규격(길이·해상도·용량·파일명)은 공식 접수가이드에서 다시 확인하세요.

## 촬영 준비

- Windows 빌드(`Builds/Windows/ProcurementHero/ProcurementHero.exe`)를 1920×1080 창 또는 전체 화면으로 실행
  (Unity Editor에서 찍는다면 Game 뷰를 1920×1080 고정 해상도로 맞추고 Maximize On Play)
- 녹화 도구: Windows는 Xbox Game Bar(Win+G) 또는 OBS, Mac은 화면 기록(Cmd+Shift+5) 또는 OBS. 60fps 권장
- 소리 설정에서 배경음은 낮게, 효과음은 켜 둠
- 튜토리얼 배너가 길게 보이지 않도록, 촬영 전 한 번 미션 1을 끝낸 뒤 "처음부터 시작"하면 튜토리얼이 다시 나오지 않습니다(같은 실행 안에서만). 튜토리얼을 보여 주려면 새로 실행하세요.

## 타임라인

| 시간 | 화면 | 조작 | 자막(예시) |
|---|---|---|---|
| 0~5초 | 타이틀: "조달 히어로" + 어두운 강당, 무더운 보건소, 물에 잠기는 대피소 | 가만히 둔다 | 새봄마을에 해결할 일이 생겼어요 |
| 5~15초 | 미션 1 화면: 주민 말풍선, 상단 예산·납기·목표 성능 | 게임 시작 → 튜토리얼 ①을 1초 보여 주고 "튜토리얼 건너뛰기" | 학교 축제가 이틀 남았어요. 강당이 어둡고 방송이 안 들려요 |
| 15~30초 | 제품 카드 비교 | 튼튼 조명 선택 → 절전 조명으로 바꿈(하단 총비용·예상 점수 변화) → 또렷 방송 선택 → 구매 확정 | 가격만이 아니라 성능, 유지비, 필요한 시점을 함께 봐요 |
| 30~45초 | 결과: 배송 차량 → 상자 도착 → 강당 조명 켜짐, 깃발, 음표 → 주민 ★ | 연출을 끝까지 보여 준 뒤 결과 패널을 2초 | 구매한 물품이 현장을 바꿔요 |
| 45~55초 | 미션 3(또는 2) 결과와 엔딩 | (미리 진행해 둔 상태에서) 대피소 배수·비상등 연출 → 엔딩 화면 "모두의 하루를 바꾼 조달 히어로" | 필요한 때 도착해야 가치가 이어져요 |
| 55~60초 | 엔딩의 세 시설 | 정지 화면 | 좋은 공공구매가 모두의 하루를 바꿔요 · 창작 게임이며 실제 제도를 재현하지 않습니다 |

## 편집 메모

- 45~55초 구간은 미션 2·3을 따로 녹화해 붙이면 60초 안에 들어옵니다.
- 미션 3에서 "장시간 전원"(배송 2일)을 골라 부분 해결 연출을 먼저 보여 주고 재도전으로 성공하는 장면을 넣으면 '납기' 메시지가 분명해집니다(시간이 남을 때).
- 마지막 자막에 "조달청 공식 제작물이 아닙니다"를 함께 넣는 것을 권장합니다.
