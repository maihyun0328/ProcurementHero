# 조달 히어로 현장 수첩 게임기획서

프로젝트명 ProcurementHero · 개편 기획안 2.0 · 작성일 2026년 11월 6일

플레이어가 조달청에서 현장 지원을 나온 담당자가 되어 문제가 있는 마을을 돌아보고, 수첩에 필요한 물품과 설치 장소를 체크한 뒤 계획을 확정하는 2D 현장 탐색 퍼즐 게임이다. 글로 읽는 설명은 줄이고 현장의 모습, 관찰, 체크 표시, 설치 전후 변화로 플레이를 전달한다.

이 문서는 새 플레이 방식을 제안하는 기획서다. 아래 미션과 비용, 평가 방식은 창작 게임 규칙이며 실제 조달청의 계약·예산·시설 설치 절차를 재현하지 않는다. 기존 프로젝트에 아직 적용된 내용은 아니다.

## 1 게임 개요

| 항목 | 내용 |
|---|---|
| 게임 제목 | 조달 히어로 마을을 바꾸는 선택 |
| 장르 | 2D 현장 탐색 및 물품 배치 퍼즐 |
| 플레이어 | 조달청에서 현장 지원을 나온 담당자 |
| 핵심 도구 | 관찰 기록과 설치 계획을 모으는 현장 수첩 |
| 엔진 | Unity Universal 2D |
| 우선 플랫폼 | Windows PC |
| 조작 | 이동은 WASD 또는 방향키, 관찰과 수첩은 클릭 중심 |
| 목표 분량 | 미션 3개, 첫 플레이 약 10분에서 15분 목표 |
| 진행 방식 | 한 미션씩 현장 탐색과 계획을 마친 뒤 다음 지역으로 이동 |
| 시각 방향 | 밝고 친근한 탑다운 2D, 명확한 문제 표현, 짧은 말풍선 |

### 플레이 경험

마을에 들어서자 골목이 어둡고, 계단 앞 주민이 발을 멈춘다. 현장을 확인하면 수첩에 계단 그림과 전구 모양의 단서가 기록된다. 플레이어는 수첩의 작은 지도에서 설치 지점을 고르고 조명에 체크한다. 확정 후 배송 차량이 들어오고 불이 켜진다. 주민이 계단을 지나가는 모습을 보며 선택의 효과를 확인한다.

### 재미의 중심

- 관찰해서 필요한 물품을 알아내는 발견의 재미.
- 한정된 예산으로 장소와 물품의 조합을 짜는 계획의 재미.
- 체크한 계획대로 현장이 달라지는 보상의 재미.

수첩의 체크는 실제로 무엇을 어디에 설치할지 결정한다. 설치 장소와 상관없이 정답 물품 하나만 체크하는 퀴즈로 만들지 않는다.

## 2 기본 플레이 흐름

| 단계 | 플레이어 행동 | 화면 반응 |
|---|---|---|
| 도착 | 담당자 캐릭터로 현장 진입 | 주민 행동과 환경으로 문제 제시 |
| 탐색 | 걸어 다니며 사람과 시설 관찰 | 관찰 아이콘 표시, 수첩에 그림 기록 |
| 계획 | 수첩에서 장소와 물품 선택 | 체크 표시, 예상 배치와 효과 범위 표시 |
| 검토 | 예산과 설치 계획 확인 | 사용 예정 비용과 미배정 장소 표시 |
| 확정 | 계획 확정 버튼 누르기 | 수첩이 닫히고 배송과 설치 진행 |
| 확인 | 변화한 현장 다시 살펴보기 | 주민 반응과 해결 여부 표시 |
| 마무리 | 결과 확인 또는 계획 수정 | 도장과 별 평가, 다음 현장으로 진행 |

### 한 미션의 상태

현장 탐색 → 수첩 계획 → 계획 확정 → 배송과 설치 → 현장 재확인 → 미션 결과.

현장 탐색과 수첩 계획은 확정 전까지 자유롭게 오갈 수 있다. 수첩은 열려 있는 동안 이동과 현장 연출을 멈추며, 닫으면 같은 위치에서 탐색을 이어간다. 설치가 시작되면 중복 확정을 차단한다.

## 3 현장 탐색

### 캐릭터와 이동

작은 담당자 캐릭터가 화면에 보이는 탑다운 방식으로 이동한다. 건물 외벽, 울타리, 물웅덩이 등의 통과할 수 없는 영역은 그림과 충돌 영역을 일치시킨다. 첫 버전은 한 화면 안에 주요 장소가 들어오는 고정 카메라로 구성한다.

### 관찰 방법

관찰 대상 가까이에 가면 돋보기 아이콘이 나타난다. 클릭 또는 E키로 관찰한다. 멀리 있는 대상은 클릭해도 관찰을 완료하지 않으며, 접근 가능한 길을 제공한다. 첫 버전에는 클릭 지점으로 자동 이동하는 기능을 넣지 않는다.

관찰 완료 시 수첩 아이콘으로 작은 그림이 이동하고, 대상에 체크가 남는다. 같은 대상을 여러 번 확인해도 기록이나 보상이 중복되지 않는다.

### 문제를 보여주는 방법

| 문제 | 긴 설명을 대신하는 표현 | 보조 문구 예시 |
|---|---|---|
| 어두운 계단 | 어둠, 발을 멈춘 주민, 계단 가장자리 | 계단이 잘 안 보여요 |
| 더운 대기실 | 부채질하는 주민, 땀, 붉은 더위 효과 | 너무 더워요 |
| 급수 부족 | 빈 물통과 컵을 든 주민 | 마실 물이 부족해요 |
| 정전 위험 | 꺼진 창문과 깜빡이는 비상등 | 전원이 필요해요 |
| 침수 위험 | 물이 고인 낮은 길과 막힌 배수구 | 물이 빠지지 않아요 |

주민 대사는 문제당 말풍선 한 개를 기본으로 한다. 관찰한 대상은 위치와 그림을 함께 기록하여 색상이나 글자만으로 구분하지 않는다.

## 4 현장 수첩

### 화면 구성

수첩은 펼친 책 형태의 화면이다. 정보는 좌우 두 페이지에 나누되 한 화면에서 현재 장소, 선택한 물품, 비용, 확정 버튼을 확인할 수 있게 한다.

| 영역 | 표시할 내용 |
|---|---|
| 왼쪽 페이지 | 현장 미니맵, 발견한 문제 그림, 설치 지점 |
| 오른쪽 페이지 | 선택 지점에 설치 가능한 물품 그림과 체크 칸 |
| 아래 영역 | 전체 설치 계획의 작은 그림 목록, 예산 게이지 |
| 오른쪽 아래 | 계획 확정 버튼 |

첫 버전은 고정 설치 지점에 체크하는 방식이다. 현장에서 물품을 직접 드래그하거나 아무 좌표에 자유롭게 놓는 기능은 넣지 않는다. 물품과 설치 위치를 수첩에서 결정한다는 사용자 의도를 중심으로 만든다.

### 장소와 물품을 체크하는 순서

1. 왼쪽 지도에서 설치 지점 하나를 고른다.
2. 오른쪽에서 해당 장소에 설치 가능한 물품이 나타난다.
3. 물품 그림 옆 체크 칸을 누르면 그 장소에 물품 한 개가 배정된다.
4. 지도에 설치 예정 그림과 범위가 나타난다.
5. 다른 장소를 골라 계획을 이어간다.
6. 준비되면 계획 확정을 누른다.

한 지점에는 물품 하나만 배정한다. 다른 물품에 체크하면 기존 배정을 교체하고, 체크된 물품을 다시 누르면 해당 배정을 취소한다. 같은 종류의 물품을 다른 지점에 배치하는 것은 가능하며 비용은 지점별로 합산한다. 물품 총수량은 배정된 지점 수에서 자동 계산한다.

### 선택과 비용

체크만 한 상태에서는 실제 구매가 이루어지지 않는다. 예산 게이지는 현재 계획에 예약된 비용을 보여준다. 교체와 취소 시에는 현재 배정 목록으로 합계를 다시 계산하며, 누를 때마다 비용을 누적 차감하지 않는다.

예산을 넘는 조합도 계획 단계에서 표시할 수 있지만, 게이지를 붉게 표시하고 확정 버튼을 비활성화한다. 설치 불가능한 물품은 해당 지점에서 체크할 수 없도록 한다.

### 확정 버튼 조건

필수 현장 관찰을 완료하고 물품을 최소 하나 배정했으며 예산 이내이면 확정할 수 있다. 관찰이 남으면 돋보기 아이콘과 남은 개수를 표시하고, 미배정이면 설치 지점 아이콘을 강조한다.

모든 문제를 해결했는지를 구매 전 문구로 정답처럼 판정해 주지 않는다. 대신 효과 범위를 확인해 스스로 판단하게 한다. 일부 장소를 놓친 계획도 확정할 수 있으며, 결과를 보고 수정한다.

## 5 설치와 결과

### 설치 연출

확정된 계획은 별도 결과 데이터로 복사하여 고정한다. 수첩이 닫히고 배송 차량이 들어와 체크한 지점 순서대로 물품이 설치된다. 상자가 열리고 물품이 나타나는 짧은 연출을 제공한다. 건너뛰면 모든 설치 결과가 즉시 같은 상태로 적용된다.

### 현장 재확인

설치 후 캐릭터를 다시 조작할 수 있다. 해결된 장소에서는 주민이 움직이거나 쉬는 등 행동을 바꾸고, 미해결 장소에서는 기존 문제가 남는다. 수첩의 마무리 페이지에는 현장 사진을 대신하는 작은 전후 그림과 해결 도장이 찍힌다. 핵심 변화 지점 한 곳을 확인하면 결과 보기를 안내한다.

### 평가

| 평가 | 조건 |
|---|---|
| 별 3개 | 필수 문제 전부 해결하고 추가 목표까지 해결 |
| 별 2개 | 필수 문제 전부 해결 |
| 별 1개 | 필수 문제를 하나 이상 해결했지만 일부가 남음 |
| 별 0개 | 필수 문제를 하나도 해결하지 못함 |

성공은 별 2개 이상이다. 별점 조건은 간단한 그림 목표로 미리 보여주고, 점수 수식이나 제품 성능 수치 목록은 기본 화면에 노출하지 않는다. 첫 버전에는 시간 보너스와 무작위 고장 판정을 넣지 않는다.

### 수정과 진행

성공하면 다음 현장으로 이동할 수 있고, 별이 부족하면 해당 미션을 다시 계획할 수 있다. 재계획은 비용이나 설치를 누적하는 방식이 아니라 이전 확정 전 상태로 되돌려 대체 계획을 세우는 방식이다. 재계획 결과가 확정되면 해당 미션의 결과를 교체한다. 결과 취소 전의 별점을 계속 더하지 않는다.

추가 목표에 실패했어도 별 2개이면 진행 가능하다. 미션에 실패하면 수첩에서 미해결 장소를 강조하여 재도전 방향을 알려준다.

## 6 미션 구성

### 미션 1 밤길을 밝혀라

새봄마을의 저녁 골목을 배경으로 한다. 플레이어는 입구, 계단, 골목을 살펴 어두운 길을 발견한다. 공원은 추가 목표 지역이다. 관찰을 마치면 수첩에서 조명 물품을 체크한다.

필수 문제는 A 마을 입구, B 계단, C 안쪽 골목의 어둠이다. D 공원은 추가 목표다. 이 표의 A부터 D는 개발용 식별자이며 게임에서는 장소 그림과 짧은 이름으로 표시한다.

| 물품 | 비용 | 특징 |
|---|---:|---|
| 가로등 | 35 | 지정 지점 주변을 넓게 밝힘 |
| 보행등 | 20 | 지정 지점의 가까운 장소를 밝힘 |

미션 예산은 75다. 다음 효과 관계를 맵의 실제 조명 표현과 일치시킨다.

| 설치 지점 | 가로등을 설치하면 | 보행등을 설치하면 |
|---|---|---|
| 입구 갈림길 | A 입구와 B 계단 | A 입구 |
| 계단 위 갈림길 | B 계단과 C 골목 | B 계단 |
| 공원 가장자리 | D 공원 | D 공원 |

첫 버전의 해결 판정은 위의 명시된 장소 집합으로 계산한다. 두 조명이 같은 장소를 비추면 한 번만 해결된 것으로 센다. 예상 효과는 지도 위 해당 장소의 강조와 실제 조명의 밝아지는 영역으로 함께 보여준다. 가짜 범위 원만 표시하고 실제 판정은 다르게 적용하지 않는다.

#### 배치 예시

| 계획 | 비용 | 결과 |
|---|---:|---|
| 두 갈림길에 가로등 하나씩 | 70 | A와 B와 C 해결로 별 2개 |
| 입구에 보행등과 계단 위에 가로등과 공원에 보행등 | 75 | A와 B와 C와 D 해결로 별 3개 |
| 입구에 가로등과 계단 위에 보행등 | 55 | C 골목이 남아 별 1개 |
| 세 지점에 가로등 하나씩 | 105 | 예산 초과로 확정 불가 |

모든 물품을 가장 비싼 것으로 고르는 것보다 현장에 맞는 배치가 유리하도록 한다. 관찰한 계단이 밝아지면 주민이 멈추지 않고 지나가는 연출로 해결을 보여준다.

### 미션 2 시원한 보건소

사람들이 대기하는 보건소에서 더위와 급수 부족을 확인한다. 냉방장치와 급수장치를 서로 다른 설치 지점에 체크한다. 냉방장치의 영향 장소와 주민 동선을 지도에 보여준다.

필수 목표는 대기 공간의 더위 해소와 급수 장소 확보다. 추가 목표는 실외 대기 주민의 불편을 줄이는 것이다. 구체적인 비용, 공간별 효과, 추가 물품은 미션 1 조작 검증 후 확정한다. 어느 한 필수 기능을 빠뜨린 채 비싼 장치에 예산을 몰아주면 일부 문제가 남도록 한다.

### 미션 3 비 오기 전 대피소

먹구름이 다가오는 대피소에서 꺼진 비상등과 물이 고인 진입로를 관찰한다. 비상전원과 배수장치를 필요한 지점에 체크하여 전력과 배수 문제를 함께 해결한다.

필수 목표는 대피소 전력 확보와 필수 진입로 배수다. 추가 목표는 보조 통로까지 확보하는 것이다. 비용과 효과 범위는 미션 1 검증 후 조정한다. 긴장감은 비와 구름의 연출로 전달하고, 첫 버전에서는 시간 제한으로 플레이어를 재촉하지 않는다.

## 7 화면과 글자 사용

### 현장 화면

현장과 캐릭터가 화면의 중심이다. 오른쪽 아래에 수첩 버튼을 두고 새 기록이 생기면 체크 애니메이션으로 알린다. 상단에는 현재 목표 그림과 예산 아이콘 정도만 표시한다. 지속적으로 열려 있는 제품 설명 패널은 제거한다.

### 글자 기준

- 주민 말풍선은 한 번에 한두 줄, 한 화면에 하나를 기본으로 한다.
- 물품은 그림과 이름과 가격을 우선 표시한다.
- 특징은 빛 범위, 바람, 물방울, 전원 등의 그림으로 표시한다.
- 처음 보는 아이콘은 짧은 이름과 함께 한 번 안내하고 이후에도 선택해서 설명을 볼 수 있게 한다.
- 효과음과 색상만으로 필수 정보를 전달하지 않는다.
- 긴 정책 설명과 출처는 타이틀의 별도 소개 화면에서 확인한다.

### 조작 안내

| 입력 | 현장 | 수첩 |
|---|---|---|
| WASD와 방향키 | 이동 | 방향키로 항목 이동 |
| 마우스 클릭 | 가까운 대상 관찰 | 장소 선택과 물품 체크 |
| E와 Enter | 가까운 대상 관찰 | 선택 항목 실행 |
| Tab 또는 수첩 버튼 | 수첩 열기 | 수첩 닫기 |
| Esc | 일시정지 | 변경한 계획을 유지하고 수첩 닫기 |

수첩을 닫거나 버튼을 숨길 때 키보드 선택이 사라지지 않도록 한다. 수첩을 닫고 다시 열면 계획과 선택한 장소를 유지한다. 배송 연출에서는 화면에 건너뛰기 버튼을 제공한다.

## 8 그래픽과 사운드

### 필요한 자산

| 구분 | 1차 제작 범위 |
|---|---|
| 플레이어 | 담당자 1명과 네 방향 이동 표현 |
| 현장 | 골목과 공원 맵 1개부터 제작 |
| 주민 | 걷기와 대기와 기쁨을 표현하는 공통 캐릭터 |
| 수첩 | 펼친 책 배경과 체크 표시와 도장과 페이지 탭 |
| 물품 | 가로등과 보행등 아이콘 및 설치된 모습 |
| 효과 | 어둠과 조명 범위와 관찰 강조와 해결 표시 |
| 배송 | 트럭과 상자와 설치 효과 |

도형과 임시 그림으로 먼저 완주 가능한 버전을 만든 뒤 그림을 교체한다. 수첩 배경에 글자를 합쳐 그리지 않고 제목과 수치와 물품명은 Unity UI 텍스트로 표시한다. 물품과 건물과 주민은 독립된 이미지나 프리팹으로 구성한다.

### 소리

수첩 펼치기, 체크, 체크 취소, 계획 확정, 배송 도착, 설치, 해결 도장의 소리를 구분한다. 배경음은 현장 관찰을 방해하지 않게 작게 재생한다. 소리를 꺼도 모든 목표와 결과를 확인할 수 있어야 한다.

## 9 Unity 제작 범위와 기존 프로젝트 개편

### 우선 완성할 최소 버전

미션 1의 맵 하나에서 이동, 필수 장소 관찰, 수첩 열기, 세 설치 지점과 두 물품의 조합, 예산 계산, 확정, 설치, 별 평가, 재계획까지 완주 가능하게 만든다. 이 흐름이 이해되고 재미있는지 확인한 뒤 보건소와 대피소를 추가한다.

### 기존 요소의 처리

| 기존 요소 | 개편 방향 |
|---|---|
| 미션 선택과 타이틀 | 화면 흐름을 맞춰 재사용 |
| 긴 제품 비교 카드 | 수첩의 물품 그림과 체크 칸으로 교체 |
| 물품 A와 B를 하나씩 고르는 규칙 | 지점마다 물품을 배정하는 규칙으로 교체 |
| 제품 성능과 납기 중심 점수식 | 장소별 문제 해결과 별 평가로 교체 |
| 예산 초과 차단 | 새 배정 목록의 총비용 기준으로 유지 |
| 배송과 시설 변화 | 체크한 지점별 설치 연출로 확장 |
| 소리 설정과 한글 폰트 | 사용 조건과 현재 동작을 확인해 재사용 |
| 기존 점수 테스트 | 기존 기능 검증용으로 보존하고 새 규칙 테스트 추가 |

기존 두 제품용 점수 계산 함수를 새 배치 판정에 억지로 적용하지 않는다. 새 결과는 미션 ID, 지점별 물품 배정, 총비용, 해결된 문제 ID, 필수 해결 여부, 별 개수를 보관한다. 수첩 화면과 결과 화면은 같은 판정 로직을 사용한다.

### 처음에 제외할 기능

자유 건축, 물품 회전, 여러 층, 온라인 기능, 실시간 생성형 AI 대화, 무작위 재난, 물품 고장 확률, 시간 제한, 복잡한 전기 배선은 이후 검토한다. 첫 버전의 선택 결과는 항상 재현 가능하게 한다.

## 10 제작 순서와 완료 기준

| 순서 | 제작 내용 | 완료 기준 |
|---|---|---|
| 1 | 맵과 이동 | 모든 관찰 지점에 접근 가능하고 건물을 통과하지 않음 |
| 2 | 관찰과 기록 | 필수 3개를 기록하며 중복 기록이 없음 |
| 3 | 수첩과 체크 | 장소마다 물품 하나를 배정하고 취소와 교체 가능 |
| 4 | 비용과 효과 | 비용이 현재 계획만 반영하고 예상 범위가 판정과 일치 |
| 5 | 확정과 설치 | 연타로 중복 구매되지 않고 모든 지점에 계획대로 설치 |
| 6 | 결과와 재계획 | 별 0개부터 3개까지 판정하고 이전 결과를 정확히 교체 |
| 7 | 표현과 안내 | 그림만으로 문제를 알아보고 필요한 설명을 선택해 확인 |
| 8 | 미션 확장 | 미션 1 검증 뒤 나머지 두 맵의 수치와 배치 관계 확정 |

### 반드시 확인할 사례

- 관찰하지 않은 필수 지점이 있을 때 확정 차단 이유가 이해된다.
- 물품 교체와 체크 취소 뒤 비용이 남거나 중복되지 않는다.
- 같은 장소를 두 물품이 해결해도 해결 수가 중복되지 않는다.
- 예산 75는 허용하고 76 이상은 차단한다.
- 미션 1의 예시 배치가 각각 별 1개와 2개와 3개로 판정된다.
- 수첩을 닫았다 열어도 선택한 물품과 장소가 유지된다.
- 확정 연타와 배송 건너뛰기 후 결과가 동일하다.
- 재계획하면 설치물과 이전 별점이 중복되지 않는다.
- 키보드만으로 관찰과 체크와 확정까지 진행할 수 있다.
- 초심자에게 설명을 읽어 주지 않아도 첫 현장에서 다음 행동을 찾을 수 있다.

## 11 공모전 제출 준비

기획의 중심 메시지는 현장을 관찰하고 공공의 필요에 맞는 물품을 골라 생활을 개선한다는 것이다. 실제 제도를 설명하는 문구는 공식 자료로 확인한 범위만 사용한다. 본 기획서의 담당자 역할과 현장 설치 흐름은 홍보와 체험을 위한 가상 설정이다.

출품 전에는 공식 모집요강과 접수가이드에서 참가 조건, AI 활용 증빙, 제출 형식과 권리 조건을 확인한다. 이 기획서 자체는 해당 조건의 충족을 보증하지 않는다.
